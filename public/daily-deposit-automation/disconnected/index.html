Disconnect instructions

To disconnect Daily Deposit Automation, sign into QuickBooks Online as an administrator and use the connected-app controls to revoke its access. Contact john@bridgwaterauto.com if you need help identifying the connection.

After revocation takes effect, the application cannot continue authorized API access using that connection. Existing deposits, journal entries, and other accounting records remain in QuickBooks. Disconnection does not reverse transactions or automatically delete source reports, reconciliation files, logs, or backups.

This page provides instructions only. Opening it does not disconnect your QuickBooks company. For questions about retained application data, see the Privacy Policy or contact the operator. For a new authorized connection, see Connect or reconnect QuickBooks.
