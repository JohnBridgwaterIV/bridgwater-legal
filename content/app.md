# Daily Deposit Automation

Daily Deposit Automation is Bridgwater Automotive LLC's private desktop accounting tool for authorized internal users. It is being developed to reconcile payment and payout activity, transaction fees, and bank-deposit records in an authorized QuickBooks Online company.

## Open the application

Run Daily Deposit Automation from its installed business computer. This public information page does not launch the desktop program or provide access to accounting records.

## QuickBooks connection

A production-capable desktop runner is available for administrator-managed installation. An authorized administrator must complete the production connection, credential setup, and source-report sign-in before automatic deposit processing is enabled.
